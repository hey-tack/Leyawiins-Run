This is a next.js static web app, for the [Leyawiins' Run](https://leyawiinsrun.org) event. 

## What is Leyawiins' Run? 

It's a (probably) one time, virtual in-game event, hosted by me, in the game [World of Warcraft: Forever](https://us.shop.battle.net/en-us/product/world-of-warcraft-forever]).

If you're interested, please check out the [the site](https://leyawiinsrun.org) for more details about the event itself, when it's happening, how to participate etc.
